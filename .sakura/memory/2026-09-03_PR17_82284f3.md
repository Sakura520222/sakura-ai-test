## 2. 发现的模式

**代码模式**
- **双依赖源并存**：requirements.txt 与 pyproject.toml 各自声明 pytest，本次同步但无机制保证后续不漂移（审查靠人工核对确认）。

- **文档驱动习惯良好**：README 与 CLAUDE.md 命令同步更新，无遗漏。

**架构观察**
- 项目以 `source = { virtual = "." }` 锁定为非打包应用（无 `[build-system]`），当前合理；若未来需 `pip install -e .` 或代码被外部导入，需补 build-backend——可预留观察。
- 结合项目记忆，本仓库为 Agent 测试场，PR 以小型 chore 为主，审查深度应与此校准。
